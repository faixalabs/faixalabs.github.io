# faixalabs.com

Sitio de Faixa Labs, servido con GitHub Pages en https://faixalabs.com.
Cada repo de app con Pages activado aparece automáticamente en `faixalabs.com/<repo>/`.

Secciones alojadas en este repo (para apps cuyo repo es privado y no puede tener Pages propio):

- `kratos/` → `faixalabs.com/kratos/` · Kratos BJJ: info, privacidad, términos y eliminación de cuenta.
